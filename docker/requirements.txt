#     (HarrisonKramer/optiland -> optiland/optiland). The old path still
#     redirects, but registry/knowledge entries should cite the new org.
#   - optiland: PyPI package does not depend on torch. The differentiable
#     GPU backend is opt-in and requires installing torch separately (done
#     below) and selecting it at runtime.
